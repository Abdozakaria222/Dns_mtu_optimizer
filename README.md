# Net Optimizer – نسخة الموبايل (Android)

بيقيس أفضل **DNS** وأفضل **MTU** (كل واحد لوحده)، وبيعرض الـ Latency والـ Jitter والـ Loss،
وبيحفظ النتيجة تلقائياً في ملف CSV.

## إزاي تطلّع الـ APK (من غير ما تثبّت أي حاجة على جهازك)

1. اعمل حساب على GitHub، واعمل Repository جديد (Private عادي).
2. ارفع محتويات المجلد ده كلها، **بما فيها مجلد `.github`** (من كمبيوتر: Add file ← Upload files ← اسحب الملفات).
   لو من الموبايل: ارفع الملفات العادية، وبعدين Add file ← Create new file واكتب الاسم
   `.github/workflows/build-apk.yml` والصق محتوى الملف.
3. افتح تبويب **Actions** ← **Build APK** ← **Run workflow**.
4. استنى 15–30 دقيقة (أول مرة بس). لما يخلص، افتح التشغيل ونزّل **NetOptimizer-apk** من Artifacts.
5. فك الضغط، وثبّت ملف `.apk` (لازم تسمح بالتثبيت من مصدر غير معروف).

## ملاحظات مهمة

- أندرويد **مبيسمحش** لأي تطبيق يغيّر DNS أو MTU للنظام من غير root. لذلك التطبيق بيقيس ويختار الأفضل،
  وبعدين بتطبّقه إنت:
  - **DNS:** إعدادات ← الشبكة ← Private DNS ← اكتب الاسم اللي بينسخه التطبيق (متاح لبعض المزودين)،
    أو من إعدادات الواي فاي ← IP settings ← Static ← DNS 1 / DNS 2.
  - **MTU:** من إعدادات الراوتر أو تطبيق VPN، أو بالروت: `ip link set dev wlan0 mtu <القيمة>`.
- اختبار MTU بيستخدم أمر `ping` الموجود في الموبايل بعلامة Don't-Fragment. لو الموبايل أو الشبكة مش بتدعمها
  هيقولك السبب بدل ما يديك رقم غلط. بعض الشبكات (خصوصاً داتا الموبايل) بتمنع ping.
- ملفات الـ CSV بتتحفظ في فولدر التطبيق (`Android/data/org.netopt.netoptimizer/files/results`)، وفيه زر **Share** يبعتها
  لأي تطبيق (Drive / واتساب / ميل).
- اترك التطبيق مفتوح قدامك أثناء الاختبار.
